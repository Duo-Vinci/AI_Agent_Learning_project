## 一、什么是 .env 文件？

`.env` 文件用于存储敏感配置信息（如 API 密钥），避免硬编码到代码中。

---

## 二、基本格式

```env
# 基本格式
KEY=VALUE

# 注意事项
# 1. 不使用引号（除非值包含空格）
# 2. 等号两侧不要有空格
# 3. 注释以 # 开头
# 4. 敏感信息不要提交到版本控制
```

---

## 三、DeepSeek 配置

```env
# DeepSeek API 配置
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxxxx
DEEPSEEK_API_BASE=https://api.deepseek.com/v1
DEEPSEEK_MODEL=deepseek-v4-flash
```

### 获取 API Key

访问 [DeepSeek Platform](https://platform.deepseek.com/) 注册并获取。

## 四、OpenAI 配置

```env
# OpenAI API 配置

OPENAI_API_BASE=https://api.openai.com/v1
OPENAI_MODEL=gpt-3.5-turbo
```

### 获取 API Key

访问 [OpenAI Platform](https://platform.openai.com/) 注册并获取。

## 五、在 Python 中使用

### 安装依赖

```bash
pip install python-dotenv
```

### 加载环境变量

```python
from dotenv import load_dotenv
import os

# 加载 .env 文件
load_dotenv()

# 读取环境变量
api_key = os.getenv("DEEPSEEK_API_KEY")
model = os.getenv("DEEPSEEK_MODEL", "deepseek-v4-flash")  # 带默认值
```

## 六、配置文件位置

在每个项目目录下创建 `.env` 文件：

```
projects/01-langchain-basics/
├── .env           # 实际配置（不提交）
├── .env.example   # 示例配置（提交）
└── src/
    └── basic_llm.py
```

---

## 七、.gitignore 配置

确保 `.env` 文件不被提交到版本控制：

```gitignore
# .gitignore
.env
*.env
```

---

## 八、代码中的自动切换

```python
# 优先使用 DeepSeek
api_key = os.getenv("DEEPSEEK_API_KEY")
if api_key:
    base_url = os.getenv("DEEPSEEK_API_BASE", "https://api.deepseek.com/v1")
    model = os.getenv("DEEPSEEK_MODEL", "deepseek-v4-flash")
else:
    # 回退到 OpenAI
    api_key = os.getenv("OPENAI_API_KEY")
    base_url = os.getenv("OPENAI_API_BASE", "https://api.openai.com/v1")
    model = os.getenv("OPENAI_MODEL", "gpt-3.5-turbo")
```

## 九、常见问题

### Q: ModuleNotFoundError: No module named 'dotenv'

**解决**：
```bash
pip install python-dotenv
```

### Q: 环境变量读取为空

**检查**：
1. `.env` 文件是否在正确位置
2. 是否调用了 `load_dotenv()`
3. 变量名是否正确
