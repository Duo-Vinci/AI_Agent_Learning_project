# 成本控制策略

## 1. 概述

AI Agent应用的成本主要来源于API调用、Token使用和计算资源消耗。本文档提供全面的成本控制策略，帮助开发者在保证服务质量的同时，有效降低运营成本。

### 1.1 成本构成分析

**典型AI应用的成本结构**：
- API调用费用：60-70%
- Token使用费用：20-30%
- 基础设施费用：5-10%
- 存储和带宽费用：3-5%

**不同模型的成本对比**（2024年价格）：

| 模型 | 输入价格(/1M tokens) | 输出价格(/1M tokens) | 适用场景 |
|------|---------------------|---------------------|---------|
| GPT-4 Turbo | $10.00 | $30.00 | 复杂推理、高质量输出 |
| GPT-3.5 Turbo | $0.50 | $1.50 | 一般对话、简单任务 |
| Claude 3 Opus | $15.00 | $75.00 | 最高质量要求 |
| Claude 3 Sonnet | $3.00 | $15.00 | 平衡性能和成本 |
| Claude 3 Haiku | $0.25 | $1.25 | 高频简单任务 |

## 2. Token使用优化

### 2.1 Prompt优化策略

**策略1：精简Prompt**

```python
# 优化前：冗长的Prompt（约200 tokens）
verbose_prompt = """
你是一个非常专业的客服助手。你需要帮助用户解决问题。
在回答问题时，你应该保持礼貌、专业和友好的态度。
请根据用户的问题提供准确的答案。
如果你不确定答案，请告诉用户你不确定。
请记住要始终站在用户的角度思考问题。

用户问题：{question}
"""

# 优化后：精简Prompt（约50 tokens）
concise_prompt = """
作为客服助手，专业解答用户问题。不确定时明确说明。

问题：{question}
"""

# 成本节省：75%的Prompt token
```

**策略2：使用System Message**

```python
from openai import OpenAI

client = OpenAI()

# 方法1：所有内容放在user message（低效）
response = client.chat.completions.create(
    model="gpt-4",
    messages=[
        {"role": "user", "content": f"你是Python专家。请解释：{question}"}
    ]
)

# 方法2：使用system message（高效，可缓存）
response = client.chat.completions.create(
    model="gpt-4",
    messages=[
        {"role": "system", "content": "你是Python专家"},  # 可缓存
        {"role": "user", "content": question}
    ]
)

# 优势：system message在多次调用中可以被缓存
```

**策略3：动态Prompt长度**

```python
class AdaptivePromptManager:
    """自适应Prompt管理器"""
    
    def __init__(self):
        self.prompt_templates = {
            "simple": "回答：{question}",
            "standard": "作为专家，请回答：{question}
要求：准确、简洁",
            "detailed": """作为领域专家，请详细回答：{question}
            
要求：
1. 提供准确的信息
2. 包含相关示例
3. 解释核心概念
4. 给出实践建议"""
        }
    
    def select_template(self, question, complexity="auto"):
        """根据问题复杂度选择模板"""
        if complexity == "auto":
            # 根据问题长度和关键词判断复杂度
            if len(question) < 20 or any(kw in question for kw in ["是什么", "定义"]):
                complexity = "simple"
            elif len(question) < 100:
                complexity = "standard"
            else:
                complexity = "detailed"
        
        return self.prompt_templates[complexity]
    
    def build_prompt(self, question):
        """构建优化的Prompt"""
        template = self.select_template(question)
        return template.format(question=question)

# 使用示例
manager = AdaptivePromptManager()

# 简单问题使用简单模板
simple_prompt = manager.build_prompt("什么是Python？")
print(f"简单问题Prompt长度: {len(simple_prompt)}")

# 复杂问题使用详细模板
complex_prompt = manager.build_prompt("请详细解释Python中的装饰器模式，包括实现原理、使用场景和最佳实践")
print(f"复杂问题Prompt长度: {len(complex_prompt)}")

# 成本节省：根据需求调整，平均节省30-50%
```

### 2.2 响应长度控制

**策略1：使用max_tokens限制**

```python
def controlled_generation(prompt, expected_length="short"):
    """控制生成长度"""
    length_configs = {
        "short": {"max_tokens": 150, "temperature": 0.3},
        "medium": {"max_tokens": 500, "temperature": 0.5},
        "long": {"max_tokens": 1500, "temperature": 0.7}
    }
    
    config = length_configs.get(expected_length, length_configs["medium"])
    
    response = client.chat.completions.create(
        model="gpt-4",
        messages=[{"role": "user", "content": prompt}],
        max_tokens=config["max_tokens"],
        temperature=config["temperature"]
    )
    
    return response.choices[0].message.content

# 成本分析
short_response = controlled_generation("什么是API？", "short")
# 预期成本：~$0.0005（输入50 + 输出150 tokens）

long_response = controlled_generation("详细解释API设计原则", "long")
# 预期成本：~$0.0045（输入50 + 输出1500 tokens）

# 通过精确控制长度，避免不必要的token消耗
```
