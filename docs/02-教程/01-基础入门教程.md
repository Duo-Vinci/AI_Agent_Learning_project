## 一、项目概述

本项目是 LangChain 的基础入门示例，演示如何调用大语言模型、创建提示词模板和构建执行链。

**项目位置**：`projects/01-langchain-basics/`

**学习目标**：
- 学习如何配置和调用大语言模型
- 理解提示词模板的作用
- 掌握 Chain 的基本概念

---

## 二、核心概念

### 2.1 大语言模型(LLM)

大语言模型是能够理解和生成人类语言的 AI 模型，如 GPT、DeepSeek 等。

### 2.2 提示词模板(Prompt Template)

提示词模板是用于格式化输入的模板，它定义了：
- 系统消息（System Prompt）：告诉 AI 它的角色
- 用户消息（User Prompt）：用户输入的格式

### 2.3 执行链(Chain)

Chain 是将多个组件连接在一起的管道：
```
用户输入 → 提示词模板(格式化) → LLM(生成回答) → 返回结果
```

## 四、代码解析

### 4.1 加载环境变量

```python
load_dotenv()
api_key = os.getenv("DEEPSEEK_API_KEY")
api_base = os.getenv("DEEPSEEK_API_BASE", "https://api.deepseek.com/v1")
model_name = os.getenv("DEEPSEEK_MODEL", "deepseek-v4-flash")
```

> 📖 **详细说明**：见 [[环境变量配置指南]]

**作用**：从 `.env` 文件中读取配置信息。

### 4.2 初始化 LLM

```python
llm = ChatOpenAI(
    model=model_name,
    temperature=0.7,
    api_key=api_key,
    base_url=api_base
)
```

**参数说明**：
- `model`: 使用的模型名称
- `temperature`: 回答的随机性（0=确定，1=创意）
- `api_key`: API 密钥
- `base_url`: API 服务地址

### 4.3 创建提示词模板

```python
prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一个乐于助人的AI助手，用中文回答问题。"),
    ("user", "{question}")
])
```

**作用**：定义对话格式，`{question}` 是占位符，会被实际问题替换。

### 4.4 构建 Chain

```python
chain = prompt | llm
```

**作用**：使用管道符 `|` 将提示词模板和 LLM 连接起来。

### 4.5 执行 Chain

```python
response = chain.invoke({"question": "什么是LangChain?"})
print(response.content)
```

**作用**：传入用户问题，执行 Chain 并获取结果。

## 六、注意事项

1. **API Key 安全**：不要将 API Key 提交到版本控制
2. **模型选择**：不同模型有不同的特点和价格
3. **temperature 参数**：值越高回答越有创意，值越低回答越确定
