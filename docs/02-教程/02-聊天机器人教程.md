## 二、核心概念

### 2.1 为什么需要对话历史？

大语言模型本身**没有记忆能力**，它不知道你们之前聊过什么。

所以每次对话都需要把：
1. 系统消息（角色设定）
2. 之前所有的对话（历史记录）
3. 最新的问题

一起发给大模型，这样它才能理解上下文。

## 四、消息类型

### SystemMessage

```python
from langchain_core.messages import SystemMessage

SystemMessage(content="你是一个友好的聊天机器人，用中文回答问题。")
```

**作用**：给 AI 设定角色和行为准则。

### HumanMessage

```python
from langchain_core.messages import HumanMessage

HumanMessage(content="你好")
```

**作用**：用户发送的消息。

### AIMessage

```python
from langchain_core.messages import AIMessage

AIMessage(content="你好！有什么我可以帮你的吗？")
```

**作用**：AI 返回的消息。

## 五、代码解析

### 5.1 初始化对话历史

```python
messages = [
    SystemMessage(content="你是一个友好的聊天机器人，用中文回答问题。")
]
```

### 5.2 添加用户消息

```python
messages.append(HumanMessage(content=user_input))
```

### 5.3 获取 AI 回复

```python
response = llm.invoke(messages)
messages.append(AIMessage(content=response.content))
```

## 七、注意事项

1. **Token 消耗**：每次对话会发送完整历史，注意成本
2. **历史限制**：可以限制历史消息数量，避免超出 Token 限制
3. **退出命令**：输入 `exit` 退出对话
