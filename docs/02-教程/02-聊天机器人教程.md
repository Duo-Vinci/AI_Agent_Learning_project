# 聊天机器人项目教程

## 一、项目概述

本项目演示如何使用 LangChain 构建一个简单的聊天机器人，支持多轮对话和上下文保持。

**项目位置**：`projects/02-langchain-chatbot/`

**核心功能**：
- 支持多轮对话
- 保持对话历史
- 使用 DeepSeek/OpenAI API

---

## 二、核心概念

### 2.1 消息类型

LangChain 中有三种主要的消息类型：

| 消息类型 | 说明 | 用途 |
|---------|------|------|
| `SystemMessage` | 系统消息 | 设定 AI 的角色和行为准则 |
| `HumanMessage` | 用户消息 | 用户输入的内容 |
| `AIMessage` | AI消息 | AI 的回复内容 |

### 2.2 对话历史机制

**关键点**：大语言模型本身**没有记忆能力**！

每次对话都需要把完整的对话历史发送给大模型，这样它才能理解上下文。

## 四、代码解析

### 4.1 初始化对话历史

```python
messages = [
    SystemMessage(content="你是一个友好的聊天机器人，用中文回答问题。")
]
```

**作用**：设置系统提示词，告诉 AI 它的角色和行为方式。

### 4.2 添加用户消息

```python
user_input = input("你: ")
messages.append(HumanMessage(content=user_input))
```

**作用**：将用户输入添加到对话历史中。

### 4.3 调用大模型

```python
response = llm.invoke(messages)
messages.append(AIMessage(content=response.content))
```

**作用**：
1. 将完整的对话历史发送给大模型
2. 接收 AI 的回复
3. 将回复添加到对话历史中，供下一轮使用

---

## 五、执行流程

```
用户输入 → 添加到 messages → 调用 LLM → 接收回复 → 添加到 messages → 显示回复
     ↓                                    ↓
  循环往复                              循环往复
```

### 完整流程图

```
开始
  ↓
初始化 LLM 和对话历史
  ↓
┌─────────────────────────────────┐
│ 用户输入消息                      │
└───────────┬─────────────────────┘
            ↓
   添加到 messages 列表
            ↓
   调用 llm.invoke(messages)
            ↓
   接收 AI 回复
            ↓
   添加到 messages 列表
            ↓
   显示回复给用户
            ↓
   输入 exit 退出？
     ├─ 是 → 结束
     └─ 否 → 回到循环开始
```

## 六、运行步骤

### 6.1 安装依赖

```bash
pip install langchain langchain-openai python-dotenv
```

### 6.2 配置环境变量

在 `projects/02-langchain-chatbot/` 目录下创建 `.env` 文件：

```env
DEEPSEEK_API_KEY=your-api-key-here
DEEPSEEK_API_BASE=https://api.deepseek.com/v1
DEEPSEEK_MODEL=deepseek-v4-flash
```

### 6.3 运行脚本

```bash
cd projects/02-langchain-chatbot
python src/simple_chatbot.py
```

## 八、注意事项

1. **Token 消耗**：每次对话都会发送完整历史，会消耗更多 Token
2. **上下文长度限制**：不同模型有不同的上下文长度限制
3. **安全性**：不要将 API Key 硬编码在代码中
