## 二、核心概念

### 2.1 工具调用

工具调用是指让 AI 模型根据用户的问题，自动选择并调用合适的工具来获取信息或执行操作。

### 2.2 工具定义

工具定义包括：
- 工具名称
- 工具描述（让 AI 知道何时使用该工具）
- 工具参数
- 工具函数

## 四、代码解析

### 4.1 定义工具

```python
from langchain.tools import tool

@tool
def get_weather(city: str) -> str:
    """获取指定城市的天气信息"""
    # 模拟天气数据
    weather_data = {
        "北京": "晴朗，温度25度",
        "上海": "多云，温度28度",
        "广州": "下雨，温度30度"
    }
    return weather_data.get(city, "未知城市")
```

**作用**: 定义一个获取天气的工具。

### 4.2 创建 Agent（使用 LangGraph）

```python
from langchain_openai import ChatOpenAI
from langgraph.prebuilt import create_react_agent

llm = ChatOpenAI(model="deepseek-v4-flash", temperature=0)

# 直接创建 agent，不需要手动拉取 prompt
agent_executor = create_react_agent(llm, [get_weather])
```

**作用**: 使用 LangGraph 创建一个代理，将工具和 LLM 连接起来。

### 4.3 执行工具调用

```python
# LangGraph 使用 messages 格式
result = agent_executor.invoke({"messages": [("user", "今天北京的天气怎么样？")]})

# 获取回答：取最后一条消息的内容
print(result["messages"][-1].content)
```

**作用**: 让代理分析问题并决定是否调用工具。

## 六、关键概念

### 6.1 LangGraph

这是 LangChain 官方推荐的现代 Agent 框架，简化了 Agent 的创建和使用。

### 6.2 ReAct 框架

ReAct 是一种让 AI 进行"推理+行动"的框架：
1. **推理**: 分析问题，决定是否需要调用工具
2. **行动**: 调用工具获取信息
3. **总结**: 根据工具返回结果生成最终回答

---

## 七、注意事项

1. **工具描述的重要性**: 清晰的工具描述能帮助 AI 正确判断何时使用工具
2. **参数类型**: 确保工具参数类型正确，AI 需要知道如何调用
3. **工具安全性**: 谨慎使用可能有风险的工具（如执行命令）
