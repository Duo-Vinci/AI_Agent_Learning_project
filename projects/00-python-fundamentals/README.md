# 00 - Python Fundamentals

Python core concepts and advanced features for AI Agent development.

## Subdirectories

- **01-async-programming**: Async/await, asyncio, concurrent programming
- **02-decorators**: Function decorators, class decorators, parameterized decorators
- **03-type-annotations**: Type hints, generics, Protocol, TypedDict
- **04-error-handling**: Exception handling, custom exceptions, error recovery
- **05-context-managers**: Context managers, resource management, custom contexts

## Getting Started

```bash
pip install -r requirements.txt
```

## Usage

Each subdirectory contains standalone examples and exercises.
