# 06 - Prompt Engineering

Advanced prompt engineering techniques for LLM applications.

## Subdirectories

- **01-basic-patterns**: Zero-shot, few-shot, instruction patterns
- **02-few-shot-learning**: Few-shot examples, in-context learning
- **03-chain-of-thought**: CoT prompting, reasoning chains
- **04-output-formatting**: JSON, XML, structured outputs
- **05-prompt-optimizer**: Automated prompt optimization
- **06-security**: Prompt injection prevention, safety measures
- **templates**: Reusable prompt templates

## Getting Started

```bash
pip install -r requirements.txt
cp .env.example .env
# Add your API keys to .env
```

## Usage

Each subdirectory contains practical examples and best practices.
