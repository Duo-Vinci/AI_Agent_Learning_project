# 08 - Agent Architecture

Core agent architectures and design patterns.

## Subdirectories

- **01-react-agent**: ReAct (Reasoning + Acting) agent implementation
- **02-planning-agent**: Planning-based agents with goal decomposition
- **03-memory-systems**: Short-term, long-term, and episodic memory
- **04-tool-calling**: Tool/function calling patterns
- **05-agent-debugging**: Debugging and tracing agent behavior
- **06-custom-agent**: Building custom agent architectures
- **07-agent-evaluation**: Agent performance evaluation

## Getting Started

```bash
pip install -r requirements.txt
cp .env.example .env
# Add your API keys to .env
```

## Usage

Each subdirectory contains a specific agent architecture pattern.
