## 应急处理

### 如果出现问题
1. 立即回滚到上一版本
2. 通知相关人员
3. 查看日志定位问题
4. 修复问题后重新部署

### 回滚命令

```bash
# Docker
docker stop ai-agent && docker rm ai-agent
docker run -d --name ai-agent ai-agent:previous-tag

# Kubernetes
kubectl rollout undo deployment/ai-agent -n ai-agent

# Serverless
serverless rollback --stage production
```
