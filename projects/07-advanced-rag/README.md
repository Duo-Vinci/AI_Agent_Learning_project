# 07 - Advanced RAG

Advanced Retrieval-Augmented Generation techniques and implementations.

## Subdirectories

- **01-document-loaders**: PDF, DOCX, HTML, markdown loaders
- **02-chunking-strategies**: Fixed-size, semantic, recursive chunking
- **03-embedding-comparison**: Different embedding models comparison
- **04-vector-databases**: Pinecone, Weaviate, ChromaDB, Qdrant
- **05-retrieval-strategies**: Similarity search, MMR, hybrid retrieval
- **06-evaluation**: RAG evaluation metrics and benchmarks
- **07-hybrid-search**: Combining dense and sparse retrieval
- **08-production-rag**: Production-ready RAG system

## Getting Started

```bash
pip install -r requirements.txt
cp .env.example .env
# Add your API keys to .env
```

## Usage

Each subdirectory contains examples of specific RAG techniques.
