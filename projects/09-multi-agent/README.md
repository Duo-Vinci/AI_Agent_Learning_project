# 09 - Multi-Agent Systems

Multi-agent collaboration patterns and orchestration.

## Subdirectories

- **01-sequential-agents**: Sequential agent chains
- **02-parallel-agents**: Parallel agent execution
- **03-hierarchical-agents**: Supervisor-worker hierarchies
- **04-debate-agents**: Multi-agent debate and consensus
- **05-research-team**: Research team simulation
- **06-code-review-team**: Code review agent team
- **07-autonomous-team**: Self-organizing agent teams

## Getting Started

```bash
pip install -r requirements.txt
cp .env.example .env
# Add your API keys to .env
```

## Usage

Each subdirectory demonstrates a multi-agent collaboration pattern.
