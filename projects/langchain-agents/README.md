# LangChain Agents

Agent智能体项目，学习如何构建自主决策的AI系统。

## 学习目标

- 理解 Agent 工作原理
- 学习多种 Agent 类型
- 掌握复杂任务规划

## 快速开始

```bash
pip install langchain langchain-openai python-dotenv
cp .env.example .env
python src/simple_agent.py
```
