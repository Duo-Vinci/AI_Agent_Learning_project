# LangChain Chatbot

聊天机器人项目，学习如何构建交互式对话系统。

## 学习目标

- 学习会话管理
- 掌握消息历史处理
- 理解对话上下文

## 快速开始

```bash
pip install langchain langchain-openai python-dotenv
cp .env.example .env
python src/simple_chatbot.py
```
